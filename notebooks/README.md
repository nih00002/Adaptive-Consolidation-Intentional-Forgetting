# Experimental Notebooks

This directory contains the experimental notebooks for the CpE 620 Spring 2026 final project, **Adaptive Consolidation with Intentional Forgetting for Task-Aware Continual Learning**.

## Notebooks

1. `01_MNIST_Proof_of_Concept.ipynb` — Two-task MNIST proof-of-concept experiment.
2. `02_CIFAR100_Benchmark.ipynb` — Five-task Split CIFAR-100 benchmark comparison.
3. `03_CORe50_NC_Experiment.ipynb` — Seven-task CORe50 New Classes experiment.
4. `04_CORe50_Task_Reordering.ipynb` — CORe50 task-order robustness experiment.

The notebooks are organized to reflect the experimental progression from controlled proof of concept to more challenging continual object-recognition evaluation.
